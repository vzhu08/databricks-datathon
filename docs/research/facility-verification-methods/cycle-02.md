## Experiment A. Compare ways to increase eligible queries

Freeze the 24 slots, existing allowlist, occurrence hashes and permitted inputs. Screen all 24 under every arm. H and Vincent record the source URL, publication or effective date, verbatim public query string, branch specificity, licence or permitted handling, upstream origin and rival outcomes in private. Publish counts only. A query must come entirely from an independently public source, with no private VF name, locality, address, coordinates, ID or rare tokens sent to any external service. Local evidence can select a public entry. It cannot modify its query string. Separate true no-match, ambiguous crosswalk, missing rights, public source inaccessible and plausible wrong branch.

## Experiment B. Paired provider comparison with actual Google runs

Freeze the ordered list of eligible hard-case strings from Experiment A. Run the same literal query on Google India and each available alternative (Bing India, DuckDuckGo India, Mappls) in the same session window. Use an India locale and the same language and device class where supported. Record time, displayed locale, login/access state, top five organic links and first map card using permitted locators and minimal notes. Randomize provider order per case with a recorded seed. Run every allowed spelling variant against Google and the alternatives as a separate matched query. Google results can vary with language and context, so replay measures the recorded session. [Google Search language controls](https://support.google.com/websearch/answer/13511324?hl=en)

If any provider blocks access, record that cell as blocked. Unknown Google history is a separate field. It cannot substitute for the new same-query Google observation. Limit reuse to permitted result metadata and publisher facts. Trace each candidate to its issuing source, check branch, civic address, effective date and entrance separately and collapse shared upstream records regardless of engine. A publisher page that appeared in both engines counts once. A newer map snippet repeating the same publisher row contributes zero new corroboration. Independently verified new entrances require their own locators and dated premises attribution.

Use two reviewers blinded to provider on candidate evidence when feasible. Score each paired case at campus and entrance grain. Report the counts of eligible, attempted, observed Google, observed alternative, both observed, adjudicable and blocked, plus the intersection for each alternative. Use confirmed alternative-only and Google-only outcomes over the **same paired adjudicable denominator**, and report wrong-branch outcomes among judged candidates. Report the eight public benchmark cases and the historical single case separately. No estimate applies to the 24-case cohort if the paired count is zero.

Advance an alternative for the tested cohort if at least one independently publisher-supported branch or entrance is validated beyond actual Google for the same query, with zero accepted wrong branches. Freeze candidate promotion on the first confirmed wrong branch. End after one pass over the frozen eligible and benchmark sets. If Google is unavailable, record a blocked comparison and keep descriptive outcomes only. If there are no paired gains, retain Google as the control and defer another search round until a new independent publisher, improved join scope or material geometry result is available. Budget up to four lookups per allowed query string, plus review of proposed gains. Wall time and provider yield remain unmeasured.
