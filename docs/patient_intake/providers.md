## Questions for the vendor decision

Send only after an authorized representative decides to make contact.

1. Which exact product, model build, instructions for use and manufacturer audit cover direct-to-patient English assessment in India? Provide permitted ages, pregnancy and emergency exclusions, and evidence for Indian English and intended populations.
2. Can our server submit narrative in an HTTPS body, present and correct individual extracted facts, preserve unknowns, ask adaptive follow-ups and distinguish unsupported or terminated cases from completed triage? Please show this in a sandbox with invented data, including a correction and an unmatched symptom.
3. Which party receives raw text, transcripts and identifiers? Which countries, subprocessors, logs, model-improvement uses, retention periods, deletion APIs, backup periods and statutory exceptions apply to this exact deployment?
4. What entitlement, credential scopes, security review, minimum fees, usage units, overages, support, clinical audit and production contract would our organization need? Provide an itemized sandbox and production quote and access to version-specific validation results.

For the recommended MGP path, request **Platform API Triage**, provision a dedicated trial instance, and ask for server-side OAuth credentials, permitted scopes and audit requirements. Validate one invented user, patient, survey and confirmed evidence revision with a separately costed call sequence once the approved sandbox API is available. Only the authorized representative may accept terms. For Ada, use the partner form to request an equivalent sandbox and commercial API specification. For Isabel, request the developer sandbox and the body-only transport specification using the developer page above.

## Engineering handoff

`providers.transport.Transport` performs one TLS JSON exchange against a server-supplied host, operation and headers. A process shares one transport and its non-renewing attempt quota. Each encounter supplies a shared physical-attempt budget across turns. Configuration defaults to zero physical attempts. The service must separately reserve logical turns and coordinate deployment quotas across replicas/restarts. A deadline bounds the caller wait. A slow exchange retains a concurrency slot until it exits. No automatic retry occurs, including when the vendor may have accepted a timed-out request.

A successful `received` result contains an untrusted JSON object for the selected adapter to validate. Unmatched evidence, unknown answers, missing recommendations, unrepresentable questions and permanent termination need distinct handling at the adapter/runtime boundary. Only validated provider output may become clinical guidance. Tests inject invented replies into the exchange and never select a provider.
