# National research handoff

Use the full pinned Virtue Foundation facility table as the research population. Every new source proposal must explain how the team can apply it in bulk to all 10,088 original rows, which geographies and facility types it actually covers, and how much evidence it adds. Count unknown or uncovered rows explicitly. [National plan](implementation/PLAN.md) · [Source inventory](https://github.com/vzhu08/databricks-datathon/issues/58#issuecomment-7068806840)

| Source | Role in the nationwide run |
| --- | --- |
| Virtue Foundation facilities, India Post PIN directory | Version 0 of both tables anchors the national population, original service text and postal context. [Verified counts](https://github.com/vzhu08/databricks-datathon/issues/36#issuecomment-7069028113) |
| HOT OpenStreetMap healthcare extract and the National Health Portal mirror | The frozen national batch contains 146,847 external identity/location records. Use the full batch with source-family attribution and retain competing campuses. [Collection](handoffs/ACQ-A01.md) |
| Candidate nationwide registers | Evaluate legal access, repeatable facility-level bulk acquisition, dates, join fields, overlap and incremental coverage. A directory entry supports the purpose its publisher documents. [Source scouting](https://github.com/vzhu08/databricks-datathon/issues/56) |
| Existing regional evidence and held-out material | Preserve source-specific dates, limits and lineage for applicable records. Prior Rajasthan casework and Andhra Pradesh/Telangana pilot proposals are historical context. Held-out sources are reserved for adjudicating frozen national results. [Validation record](implementation/VALIDATION_RESEARCH.md) |

Report coverage for every original row and separately for each state/UT and service. Audit a sample drawn from the national run to estimate error. Authorize new collection only when the source and method support nationwide use.
