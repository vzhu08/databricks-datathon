# Reusable UI foundation

Import the explicit client entry `src/index.tsx` and `src/theme.css` after the starter token sheet. Tokens --ink, --muted, --paper, --surface, --line, --accent, --radius are configurable. No provider SDK or server runtime is imported. Components are controlled by callbacks: FileUpload validates size/type and owns cancellation/retry; ResultsTable filters/sorts/pages; SourceViewer highlights exact end-exclusive offsets; EditableResult validates review; StreamingChat consumes an AsyncIterable; JobProgress, MetricCard, Comparison, Status and Skeleton cover common states. See the gallery at `npm run dev:showcase`, http://localhost:3001/gallery. Media permission controls, maps and scenario charts belong to their capability modules. UI browser smoke checks: `npm run test:browser`.
