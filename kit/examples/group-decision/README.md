# Group decision reference

`npm run dev:showcase` → http://localhost:3001/group. Default local session: two synthetic member preferences, hard constraints, weighted ranking and editable per-member votes. Reduce the budget to zero to see the empty pool; restore it and inspect score explanations. Votes break score ties, then stable IDs decide. For a real two-client flow, run `npm run realtime`, connect both browser sessions to ws://127.0.0.1:8788 and the same room using Alex and Sam respectively. Preferences stay local to each client in this reference; votes/presence are synchronized, and users should configure the same constraints. The server persists only in memory. Production uses authenticated Supabase or an authenticated always-running service. Independent recipe: `npm run kit -- create /tmp/group-demo --starter group`, install/run and visit /kit. Realtime module README includes its standalone server command.
