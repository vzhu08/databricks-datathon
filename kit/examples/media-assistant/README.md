# Media assistant reference

`npm run dev:showcase` → http://localhost:3001/media. Microphone/camera require browser permission and a secure context (localhost qualifies). Default mode never sends media to an external provider. Recorded audio plays locally; sample transcript is authored synthetic text, not a transcription of the tone fixture. Uploaded images are truly resized/validated locally; fixture detections apply only to the authored sample image. Text processing uses the real job worker. Configure explicit OpenAI adapters described in voice/media to add transcription, streaming speech or vision to your own server routes. Independent recipe: `npm run kit -- create /tmp/media-demo --starter media`, install/run, visit /kit. Demo worker memory is cleared on process restart and cannot provide reliable serverless background processing. Use the SQLite worker/container path for durable work on a persistent volume.
