# Requirement traceability

Source of scope: [BUILD_PROMPT.txt](../resources/source/BUILD_PROMPT.txt), version 2026-10-08, and [DEVELOPMENT_PLAYBOOK.txt](../resources/source/DEVELOPMENT_PLAYBOOK.txt). The IDs below retain the source's exact numbered sections and lettered acceptance/adaptation groups. Descriptive suffixes identify grouped bullets within those sections; they do not invent new source requirements.

This map was prepared on 2026-10-09 against the integration checkout, including work still being integrated. It links implementation, guidance, examples and the appropriate evidence location. **It is not a blanket completion or live-verification claim.** Final commands, execution outcomes, environment, revision and counts: **see [VERIFICATION.md](VERIFICATION.md)**. The [status](STATUS.md), [plan](PLAN.md) and [decisions](DECISIONS.md) describe continuity and ownership; stale branch copies are not authoritative claims.

Evidence vocabulary:

- **Implemented / local path:** concrete source, fixture/example and behavioral checks exist. Module READMEs record scoped evidence; final integrated results are in VERIFICATION.md.
- **Export/adoption/browser:** requires the actual separate-project or browser exercise, not just source inspection. See VERIFICATION.md for the executed result or explicit skip.
- **Live unverified:** real adapter logic exists, but no claim is made that this build contacted the provider, used a paid test account, sent an outbound action or deployed publicly.
- **Native/hardware unverified:** Docker, Tesseract/PDFium OCR, physical camera/microphone and additional OS/browser combinations require their own checks. A mocked permission event is not a hardware test.
- **Documented limit:** deliberately bounded supported behavior, described below and in the module guide. A limit is not concealed by fixture fallback or a “production ready” label.

## Verification boundaries to preserve in the final report

1. **Providers and outbound actions:** OpenAI/Anthropic generation/embeddings, Tavily search, speech/vision, Mapbox, Resend, Slack, Google Calendar/OAuth and Supabase account-backed behavior need explicit configured test accounts and usage intent. Ordinary fixtures do not establish those outcomes.
2. **Infrastructure/native:** Supabase Docker/RLS, Python/worker container builds, Tesseract/PDFium OCR, persistent-volume hosting and actual WebSocket deployment need their prerequisites. Local worker recovery does not establish distributed reliability.
3. **Device/OS:** physical microphone/camera, codecs, browser variants, native Windows and the documented WSL2 route are not certified by TypeScript/Python unit tests.
4. **Production semantics:** default share/room/cache state is process-local; durable sharing and distributed webhook dedupe require an application-owned persistence layer. PDF standard-font typography and complex document layout limits are disclosed.
5. **Final composition evidence:** clean-room generation/adoption, full browser flows, catalog/docs freshness, final CI and the operator handoff are judged on final integrated HEAD. **See VERIFICATION.md** for commands, results, counts and remaining skips; this map deliberately does not guess them.
