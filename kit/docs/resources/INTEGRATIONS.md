# Integration sources and verification levels

Checked 2026-10-09. Official docs/source were consulted for these implementations; local fixture contracts were exercised. Live credentials, account availability, paid behavior and production hosting are **not** established by documentation access.

| Integration                      | Implementation                        | Official source                                                                                                                                                                                                                 | Setup/cost boundary                                                       |
| -------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| OpenAI / Anthropic               | modules/ai                            | [AI SDK](https://ai-sdk.dev/docs), [OpenAI structured output](https://developers.openai.com/api/docs/guides/structured-outputs), [Anthropic](https://platform.claude.com/docs/en/api/overview)                                  | Server keys + configured model; usage may be billed                       |
| Supabase                         | modules/supabase, retrieval, realtime | [Local workflow](https://supabase.com/docs/guides/local-development/cli-workflows)                                                                                                                                              | Docker local or configured project; account/plan constraints vary         |
| Speech / vision                  | modules/voice, media                  | [OpenAI audio](https://developers.openai.com/api/docs/guides/audio), [vision](https://developers.openai.com/api/docs/guides/images-vision)                                                                                      | Explicit model/key and limits; no browser secret                          |
| Tavily search                    | modules/research                      | [Tavily search](https://docs.tavily.com/documentation/api-reference/endpoint/search)                                                                                                                                            | Provider key, quota and account terms                                     |

| Claude instructions              | CLAUDE.md import                      | [Official memory docs](https://code.claude.com/docs/en/memory)                                                                                                                                                                  | @AGENTS.md compatibility import; tool behavior varies by version/settings |

Current exact package versions are package-lock.json, not copied claims in prose. Consult module READMEs for endpoint scopes, live switches and adapter-specific limits. A coding-assistant subscription is not an application API credential or spending authorization.
