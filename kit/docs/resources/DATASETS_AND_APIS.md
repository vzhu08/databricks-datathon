# Small, useful data sources

This is a selection guide, not a promise that an API is free or currently available. Last source review: 2026-10-09. No external dataset below is bundled; kit fixtures are small original synthetic data.

| Source                                                                                                        | Intended use/access                           | Auth                          | License/use conditions                                   | Cost notes                                                |
| ------------------------------------------------------------------------------------------------------------- | --------------------------------------------- | ----------------------------- | -------------------------------------------------------- | --------------------------------------------------------- |
| [US Census APIs](https://www.census.gov/data/developers.html)                                                 | Public demographics; documented HTTP datasets | Some access supports API keys | Review dataset-specific notices and attribution          | Verify current service policies; no kit usage assumption  |
| [World Bank indicators](https://datahelpdesk.worldbank.org/knowledgebase/topics/125589-developer-information) | Country/time-series analysis                  | Public API paths              | Confirm indicator source license and attribution         | Access terms may change                                   |
| [OpenStreetMap](https://www.openstreetmap.org/copyright)                                                      | Geographic data and attribution               | Depends on service            | ODbL; map data and tile-server policies are separate     | Do not assume public tiles/geocoding permit unlimited use |
| [NASA APIs](https://api.nasa.gov/)                                                                            | Space/environment prototypes                  | API key for many endpoints    | Review image/data source rights and credit               | Check current quotas before a live demo                   |
| [Data.gov](https://data.gov/)                                                                                 | Discover government datasets                  | Dataset-specific              | Catalog presence is not a blanket redistribution license | Provider-specific                                         |

Before selecting a source, record exact dataset/version, retrieval date, allowed redistribution, required attribution, PII risk, test-account setup, quota and outage fallback. Prefer a tiny legally reusable sample with explicit provenance over an indiscriminate download. The sponsor adapter checklist is in MODULE_MANIFEST.md and INTEGRATION_NOTES.md templates.
