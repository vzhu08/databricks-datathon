## Reproduce and verify

Use the frozen inputs to reproduce revision 2. The run used Python 3.12, lxml 6.1.1 and jsonschema 4.26.0.

```sh
python -m pip install lxml==6.1.1 jsonschema==4.26.0
python -m unittest discover -s tests/research/trauma -p 'test_*.py' -v
python -m research.trauma.state.collector --html data/local/trauma/acq-b01/B1/raw/roadsafety.html --metadata data/local/trauma/acq-b01/B1/raw/retrieval.json --output-dir data/local/trauma/acq-b01/B1 --expected-count 57
```

For a fresh public capture, save the response to a new ignored directory. The successful acquisition used the following curl options with the publisher's HTTP URL. Use the registered HTTPS URL when its hostname validates.

```powershell
$raw = 'data/local/trauma/acq-b01/B1-new/raw'
New-Item -ItemType Directory -Path $raw -Force | Out-Null
$url = 'http://roadsafetycell.rkcl.in/pageView/token=d3doM0tvbjVvNmVEbkJRM2YycHVUdz09'
curl.exe --fail --silent --show-error --max-time 25 --max-filesize 5000000 --output "$raw/roadsafety.html" $url
if ($LASTEXITCODE -ne 0) { throw "Directory download failed with curl exit $LASTEXITCODE" }
@{
    source_url = $url
    retrieved_at = (Get-Date).ToUniversalTime().ToString('yyyy-MM-ddTHH:mm:ssZ')
    acquisition_method = 'public HTTP GET'
} | ConvertTo-Json | Set-Content "$raw/retrieval.json" -Encoding ascii
```

Set the optional `artifact_uri` to the original location when replaying copied inputs. When omitted, the collector uses the input file's absolute URI. The expected count is a comparison baseline.
