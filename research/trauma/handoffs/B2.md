## Reproduction

Install the lane dependencies with `python -m pip install -r research/trauma/identity/requirements.txt` using Python 3.11 or newer. From the B2 checkout use PowerShell with `$B1`, `$B2`, `$B3` and `$D` set to the paths below. If D is running from a separate checkout, invoke the script via its absolute path so its sibling imports resolve.

```powershell
python -m unittest discover -s tests/research/trauma/identity -p 'test_*.py' -v
python -m research.trauma.identity.producer --manifest "$B2/input-manifest.json" --state-batch "$B1/batch.json" --state-districts "$B1/campuses.json" --output-dir "$B2/replay"
python "$D/databricks/enrichment/validate_batch.py" --batch "$B1/batch.json" --batch "$B2/batch.json" --batch "$B3/batch.json" --base "$D/contracts/fixtures/enrichment_base.json" --as-of 2026-11-21
```

If original RGHS bytes become available, add an `rghs_pdf` source to a new local manifest with its actual source key, publisher, family, URL, path, UTC retrieval time, attribution and verified license if available. Keep the captured PDF and its manifest together. Inspect any layout warnings and reconcile extracted counts against rendered pages before handing a revised batch to the lead.

IDs use the source key and raw-byte SHA-256 for snapshots, and namespaced SHA-256 of sorted UTF-8 JSON with source snapshot, row or claim content and locator for derived rows. The local manifest freezes the retrieval timestamp and exact raw path. Identical identifier payloads in one PDF retain the first locator, with later occurrences reported. Conflicting variants retain distinct IDs.
